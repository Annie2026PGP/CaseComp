# CaseComp

Case competition prep, organized for use with [Claude Code](https://claude.ai/code).

See [`CLAUDE.md`](./CLAUDE.md) for the full project structure and
conventions. Quick start:

- `cases/<case-slug>/` — one folder per competition (brief, research,
  analysis, deck, submission).
- `templates/` — templates used when starting a new case.
- `resources/` — cross-case reference material (frameworks, past
  learnings).

To start a new case, just tell Claude Code, e.g. "start a new case for the
Acme strategy competition, due August 15."
