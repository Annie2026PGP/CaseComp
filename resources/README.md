# Resources

Cross-case reference material — things that are useful across multiple
competitions rather than specific to one case:

- Frameworks you keep reaching for (e.g. notes on Porter's Five Forces,
  unit economics, growth-share matrix) and when to use each.
- Retrospective learnings from past cases (what worked, what didn't).
- Reusable data (industry benchmarks, standard multiples) worth keeping
  around.

Add files here as plain markdown; link to them from a case's `analysis/`
notes rather than copying content in.
